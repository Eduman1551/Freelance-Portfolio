# Freelance Portfolio

Personal developer portfolio showcasing freelance web projects.

**Live:** https://freelance-portfolio-theta-seven.vercel.app/

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion / GSAP (animations)

## Features

- Hero, Projects, How I Work, and Skills sections
- Responsive design (mobile-first)
- Smooth scroll animations and hover interactions
- Project showcase linking to live deployed work

## Featured Projects

- [Aether Apparel](https://aether-apparel-frontend.vercel.app/) — E-commerce frontend
- [Maple Hearth Cafe](https://maple-hearth-cafe-project.vercel.app/) — Cafe website with reservations & admin panel

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Deployed on [Vercel](https://vercel.com).
